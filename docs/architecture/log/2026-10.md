  them; their window seams are in `globals.d.ts`). `docs/sw.js`, hand-maintained in `docs/` since
  the PWA began so that no build step could rewrite the file that decides whether a stale page can
  update itself, became `pagejs/sw.ts` under its own project (`pagejs/tsconfig.sw.json`: the
  WebWorker lib, and `moduleDetection: "force"` so the file can say `declare const self:
  ServiceWorkerGlobalScope` without a runtime export); that promise is kept by how it is built — on
  its own, never bundled, never minified, the types erased and nothing else. Both builds pass
  `--tsconfig-raw={}`: esbuild otherwise reads the root `strict` and prefixes every classic script
  with a file-wide `"use strict"` the hand files never had. Proved by building old and new with
  identifier mangling off (`--minify-syntax --minify-whitespace`): every file byte-identical but
  nav.js, whose one difference is esbuild dropping the unused Annex B aliases of three functions
  declared inside a `try` block (every caller sits inside the same block). `Domain/Fts.js`, the
  tokenizer FFI, became PureScript over `Data.String.Regex` — still a real JS RegExp, so `\S` and
  the word class keep their exact semantics; the phrase/run split is read off each whole match (a
  `\S+` run reaches a `"` first only when no closing quote follows, so it can never open and close
  with one), and the parity oracle gained nine quote-edge queries. The 144 `*.test.mjs` and
  `_support/*.mjs` files and `scripts/{response_shapes,home_prerender}.mjs` are `.ts`, run by
  Node's own type stripping; a test that evaluates a slice of shipped source (nav_shell's vm, the
  edge filter, the slug parity driver) erases its types first through esbuild
  (`tests/_support/ts.ts`). eslint is gone — it linted only the served JS, and tsc's "cannot find
  name" holds the line its `no-undef` held — but `espree`, its parser, stays as a direct
  devDependency for `tests/_support/env_flow.ts`. The `any` ratchet counts `pagejs/` with the
  client (the page scripts carry none; the baseline clicks to 2448 for two casts
  `app/appchrome.ts` no longer needs). The tests are
  type-checked too, not merely renamed: `npm run tsc` gained `tests/tsconfig.json`
  (client, kernel and script tests; DOM lib) and `tests/worker/tsconfig.json` (the worker tests
  and their helpers against `@cloudflare/workers-types`, with `@types/node` a new devDependency for
  both), every file strict with zero errors and no `@ts-` comment. The casts are the honest seams: a
  `makeEnv()` env is not the worker's branded `Env`, so a test casts it to the parameter type of
  the function it calls; a deliberately wrong input (core's coercion cases, egress's empty name
  list) is cast `as never`; a stubbed `fetch` or browser global is cast to the real type. With both
  type packages loaded, `Buffer#toString` takes no argument, so the two `gunzipSync(...).toString(
  'utf8')` reads cast to a local shape.
- **The three browser libraries come from npm, not from hand-committed bytes (2026-10-09)** — the
  owner asked why `tweetnacl.min.js`, `lamejs.min.js` and `qr.min.js` sat in `docs/` outside npm,
  and there was no reason beyond history: they predate the npm toolchain, and the history rewrite
  had erased any record of where the bytes came from. Each is now an exact pin in `dependencies`
  (`tweetnacl` 1.0.3, `@breezystack/lamejs` 1.2.7, `qrcode-generator` 1.4.4: the shipped bytes ARE
  the packages' — nacl.min.js byte-identical, the lamejs IIFE identical below its header, the QR
  minified by our esbuild and drawing identical codes across four levels and five payloads), and
  `scripts/vendor.ts` (`npm run build:vendor`, inside `build:js` before the stamp keys them) writes
  them into `docs/`, now git-ignored. They stay standalone classic scripts injected on first use,
  not imports: ~200 KB stays off every page that never seals a DM, records a voice note or shows a
  QR, and lamejs (LGPL) stays a separate, replaceable file. `tests/js/vendor.test.ts` runs each
  bare in an empty context and asks for the global the client reads (`nacl`, `lamejs`, `qrcode`),
  so a bump that changes a file's shape fails here rather than in a browser; Dependabot raises each
  runtime dependency as its own PR.
