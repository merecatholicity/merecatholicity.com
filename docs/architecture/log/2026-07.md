## Build system

**The JS toolchain is npm (2026-07-31) — deno is GONE.** The repo is now a disciplined npm project:
`package.json` + a committed `package-lock.json`, restored with **`npm ci`** into a git-ignored
`node_modules/`. Node/npm are **pacman-installed** (`/usr/bin/node`, `/usr/bin/npm`); **NEVER `sudo
npm`, never `npm install -g`** — every JS build/lint tool (Tailwind, esbuild, eslint, wrangler) is a
per-project devDependency. `esbuild` is pinned **exact** (`"0.24.2"`) for byte-stable bundles; the
rest float within the lockfile. The npm scripts are `build:css` (Tailwind), `build:js` (esbuild),
`lint` (eslint), `build` (all three), and `worker:deploy`; **the `make` targets wrap them** so `make
css`/`make bundle`/`make jscheck`/`make worker-deploy` work exactly as before. Adding a JS dep is
`npm install --save-dev <pkg>` (commit the updated lockfile). Note: npm 12 blocks package
install-scripts by default — the native binaries (esbuild/wrangler/tailwind) still arrive via their
platform optional-dependencies, so the tools run despite the `install-scripts blocked` warnings. See
README's "The JavaScript toolchain (npm)".

**The stylesheet is Tailwind (v4, CSS-first) since 2026-07-31 — single-sourced from
`styles/main.css`.** `main.css` is the Tailwind entry: it imports the tailwind **theme** +
**utilities** layers (`@import "tailwindcss/theme.css"` / `.../utilities.css`), registers the site's
design tokens in an **`@theme`** block (`--color-maroon: var(--maroon)`, etc. — mapped to the LIVE
`--var`s that `01-tokens.css` redefines under `[data-theme="dark"]`/`[data-dark]`, so
`bg-*`/`text-*`/`border-*` utilities inherit the dark/palette switching automatically, no
per-element `dark:` variant), pulls the `@tailwindcss/typography` plugin (for `prose` on the
generated reading corpus), and then carries the hand-authored CSS (design tokens, the reading
`prose` surface, and all component styles) **inlined, UNLAYERED**, keeping the exact precedence the
old `cat styles/*.css` gave (the `styles/NN-*.css` split was folded into `main.css` and retired
2026-07-31). Deliberate choices: **preflight is NOT imported** (the site keeps its own base reset —
`01-tokens.css` sets `box-sizing`, `04-base.css` the element defaults; importing preflight would
reset the reading typography across ~250 generated pages), and **automatic content-detection is
DISABLED** (`source(none)` on the utilities import) because the generated corpus prose contains
English words like "table"/"block"/"hidden" that would be emitted as spurious utilities — utility
scanning is turned on **per surface** via explicit `@source` lines added to `main.css` as each
surface is converted. `npm run build:css` (`make css`) compiles to the minified, committed,
unversioned `docs/style.css` (cache-TTL like before). Migration status (**Phase 3 DONE 2026-07-31 —
`main.css` is the only CSS source**): (1) **the reading corpus is the `.prose` surface** —
`04-base.css`'s reading typography was rescoped from global element selectors to `.prose
:where(...)` (`:where()` keeps element specificity at zero so platform component classes always
win), and every page's reading content sits in `<main class="prose">` (emitted by
`scripts/nav.py`/`partials/nav.html`, scripted into all ~265 pages; `liturgies.html`, which had no
`<main>` at all, gained the standard wrapper). Links + the image reset stay global; the mobile
`h1`/TOC override was co-scoped. (2) **the app chrome + forum stay as clean token-driven component
CSS**: an exhaustive multi-agent conversion of those surfaces to Tailwind `@apply`/utilities was run
and headless-verified, and it **empirically proved the conversion BLOATS the output (~68 KB vs 63
KB) with zero visual change** — `@apply` drags in Tailwind's utility machinery (`--tw-*`, the
`@property` polyfill, `--spacing`/`--color-*` indirection) for no benefit on stateful,
breakpoint-gated component CSS. So those surfaces stay raw (already token-driven, already in the
Tailwind build via `@theme`). Utilities-in-markup was also impossible for the ~250 generated corpus
pages. (3) all `styles/NN-*.css` were inlined into `main.css` and the split retired. Parity proven
headless throughout (byte-identical `style.css`).
